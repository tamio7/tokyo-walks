# 江戸さんぽ(散歩アプリ)

麹町永田町外桜田絵図(江戸切絵図)と現代の地図を並べて、「ここは江戸時代に何があった場所か」をたどる散歩アプリです。
ビルドは不要で、静的ファイルだけで動きます。

## 起動

```
cd app
python -m http.server 8000
```

ブラウザで http://localhost:8000/ を開きます。スマホで現在地を使うには HTTPS(または localhost)が必要です。

## 画面

- **スマホ**: 上に江戸と現在の地図(左右に並べて連動)、下に解説
- **PC**: 左に解説、右に地図(江戸が上、現在が下)

## できること

- 番号つきの史跡をタップ → 江戸時代/明治〜現在の解説、広重や明治の地図などの図版、ゆかりの味・お土産(地図アプリの検索リンク)
- 住所・場所の検索 → 両方の地図にピンを立て、「江戸時代この近くに何があったか」と近くの史跡を表示(Nominatim を使用)
- 現在地ボタン → 現在地を江戸絵図の上にも表示し、近くの史跡を距離順に表示
- 2つの地図は拡大率と中心位置が連動

## ファイル

| ファイル | 内容 |
| --- | --- |
| `index.html` / `style.css` / `app.js` | 画面とロジック |
| `data/spots.js` | スポット・屋敷のデータ(ここを足せば史跡が増える) |
| `img/` | 江戸絵図、広重の浮世絵、明治の地図など |
| `vendor/` | Leaflet 1.9.4 |

## 絵図と現代地図の位置合わせ

`data/spots.js` で `control: true` のスポット(基準点)について、絵図のピクセル座標と現代の緯度経度を対応づけています。
全体を回転・拡大した相似変換で合わせ、基準点の残差を補間しています。絵図は縮尺が一定でないため、位置は目安です。

ずれを直すには `index.html?calibrate=1` を開いて絵図や地図をクリックすると、対応する座標が表示されます。それを `spots.js` に反映してください。

## 出典・注意

- 解説は「衆議院参観、霞ヶ関あたり散歩 第89回江戸歴史散歩198」(榎本民夫)の資料をもとにしています
- 現代地図は国土地理院タイル、住所検索は OpenStreetMap Nominatim(利用規約に従い、大量アクセスは避けてください)
- お店は地図アプリの検索リンクです。営業状況は現地でご確認ください
