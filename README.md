# tokyo-walks

東京を歩いた記録を残すリポジトリです。散歩ごとにフォルダを分けて、写真と文章を置いています。

## フォルダ構成

```
tokyo-walks/
├── README.md
└── walks/
    ├── _template/                 # 新しい散歩用のひな形
    │   ├── README.md
    │   └── photos/
    └── YYYY-MM-DD-場所名/         # 散歩ごとのフォルダ
        ├── README.md              # 文章(日付・コース・感想など)
        └── photos/                # 写真(01.jpg, 02.jpg ...)
```

## 新しい散歩を追加する

1. `walks/_template` をコピーして `walks/2026-11-03-谷根千` のように名前を付ける
2. `README.md` に日付やコース、感想を書く
3. `photos/` に写真を入れ、`README.md` から参照する

## ルール

- フォルダ名は `日付-場所名`(日付は `YYYY-MM-DD`)にして、並べると時系列になるようにする
- 写真は `01.jpg`, `02.jpg` のように連番にする
- 容量が大きくなるので、写真は長辺 2000px 程度に縮小してから入れる
